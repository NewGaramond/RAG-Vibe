# RAG-Vibe

A LangGraph-orchestrated RAG app that ingests PDFs into a vector store and serves a guarded, memory-aware chat front-end with citations and automatic context summarization.


| Requisito del stakeholder                           | Estado              | Cómo lo cumplimos                                                                                       | DoD (criterio de éxito)                                                                                                                 | Prueba de aceptación (manual)                                                                                               |
| --------------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Interfaz (p.ej., Gradio)**                        | Hecho               | `src/ui/app.py` chat + citas                                                                            | UI muestra conversación, fuentes y soporta sesiones                                                                                     | Abrir app, lanzar 3 preguntas y ver streaming + citas clicables                                                             |
| **Ingesta de varios PDFs largos → Vector DB**       | Hecho               | `src/ingest/run.py` (chunking + embeddings → **Chroma**)                                                | ≥2 PDFs, ≥1k chunks indexados, consultas responden con citas correctas                                                                  | Buscar un concepto que solo aparece en 1 PDF y verificar la cita (doc/página)                                               |
| **Indexar imágenes para poder preguntar por ellas** | **Pendiente (MVP)** | Extraer figuras → **caption + tags** (LLM visión) → indexar como texto en Chroma con `modality="image"` | Dado un PDF con ≥10 imágenes únicas: consultas tipo “figura/ gráfico X” recuperan ≥1 resultado correcto con miniatura y enlace a página | Preguntar “Muéstrame el gráfico de barras de ventas mensuales” y obtener la figura correcta en el top-3                     |
| **Extracción estructurada (no en vector DB)**       | **Pendiente (MVP)** | Esquema fijo (YAML) → OCR si hace falta → extracción LLM **JSON estricto** + validación                 | En 3–5 formularios de prueba, ≥80% de campos **requeridos** pasan validación a la primera; JSON descargable                             | Cargar 3 PDFs de formularios sintéticos, ver tabla con ✅/⚠️ y descargar el JSON                                             |
| **Memoria dinámica + resumen al pasar X tokens**    | Hecho               | `src/memory/summary.py` (ventana reciente + resumen incremental)                                        | Al superar umbral, se genera/actualiza resumen sin perder fidelidad                                                                     | Lanzar 25+ turnos; comprobar que el resumen aparece en el prompt y que el contexto se mantiene                              |
| **Basado en LangChain/LangGraph**                   | Hecho               | `src/rag/graph.py` orquesta: safety → memoria → retrieval → síntesis                                    | Trazas muestran nodos invocados por turno                                                                                               | Revisar logs/tracing con timings por nodo                                                                                   |
| **Ejecutar código Python cuando sea necesario**     | **Pendiente (MVP)** | **Python Tool** seguro, invocado por política (clasificador + heurísticos)                              | 10 tests positivos (cálculos/transformaciones) pasan; 10 intentos maliciosos quedan bloqueados                                          | Preguntas “convierte 72°F a °C”, “media de [ … ]” usan la tool; intentos de `open()`/`__import__` fallan con mensaje seguro |
